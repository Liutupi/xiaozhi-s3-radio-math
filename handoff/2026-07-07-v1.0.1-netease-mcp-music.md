# v1.0.1 网易云 MCP 音乐播放交接

日期：2026-07-07

## 目标

解决“多多已接入网易云 MCP，能搜到音乐，但设备没有声音”的问题。

判断：后台/NAS 的 MCP 已经负责搜索，但固件缺少一个可被小智调用的设备侧播放入口。于是新增 `MusicPlayer` IoT 工具，让 MCP 返回的可播放 MP3 URL 能落到开发板喇叭。

## 本次源码改动

- `main/games/internet_radio.h`
  - 新增 `StartUrl(Display*, AudioCodec*, url, title)`。
  - 新增 URL 播放模式字段：`custom_stream_`、`custom_url_`、`custom_title_`。

- `main/games/internet_radio.cc`
  - 复用网络电台 MP3 解码、重采样、输出链路播放任意直链 MP3。
  - URL 模式显示 `MUSIC / MCP Music / title`。
  - URL 模式播放完成后不循环同一首歌。
  - URL 模式下切台按钮不做电台切换。

- `main/boards/bread-compact-wifi-lcd/compact_wifi_board_lcd.cc`
  - 新增 `MusicPlayerThing`。
  - 暴露 `MusicPlayer.PlayUrl(url, title)` 和 `MusicPlayer.Stop`。
  - 开始播放新电台/音乐前会先停止旧流。

- `main/iot/thing.cc`
  - 修复可选 IoT 参数未传时仍读取导致崩溃的问题。

## 后台提示词建议

如果多多还是只回复“马上播放”但不出声，在多多角色提示词里追加：

```text
当用户要求播放网易云音乐时，先使用网易云音乐 MCP 搜索歌曲并获取可播放的直链 MP3 URL；拿到 URL 后必须调用设备工具 MusicPlayer.PlayUrl，并传入 url 和 title，让开发板扬声器播放。不要只口头回复“马上播放”。
```

## 测试建议

1. 让开发板重启后连上小智后台。
2. 对多多说：“播放一首网易云音乐”。
3. 观察屏幕是否切到 `MUSIC / MCP Music`。
4. 若屏幕切换但无声，检查 MCP 返回链接是否是直链 MP3。
5. 若屏幕没有切换，检查多多是否真正调用 `MusicPlayer.PlayUrl`。
